Rekap Absensi Discord

Rekap otomatis dari react anggota di channel absensi.

Token hanya dikirim ke server web ini untuk memanggil Discord, tidak disimpan di server.
Isi kalau yang wajib absen cuma role tertentu, supaya staff atau member lain tidak ikut dihitung "tidak hadir".
Kosong = semua pesan yang ada react dihitung sebagai absensi. Diisi = hanya pesan yang mengandung kata itu (hari tanpa react tetap tercatat).
